# Luxury Motors Elite Corp. - E-Commerce & Alquiler de Vehículos Premium

Plataforma SPA (Single Page Application) desarrollada para **Luxury Motors Elite Corp.** con soporte completo para catálogo interactivo de superdeportivos y motos, pasarela de pago simulada y generación automática de facturas y contratos en PDF.

## 🚀 Características
- **Interfaz Premium Dark Mode:** Estilos con Bootstrap 5.3.3 y CSS personalizado.
- **Catálogo Dinámico:** Fotos reales en alta resolución de vehículos y motocicletas de alta gama.
- **Gestión de Alquiler y Compras:** Modales reactivos con cálculo de tarifas por día/hora y depósitos de garantía.
- **Generación de PDF Infallible:** Utiliza `html2pdf.js` sin congelamiento de pantalla ni textos invisibles.
- **Pie de Página Oficial:** Personalizado a nombre de **Angelis Trejo**.

## 🛠️ Tecnologías Utilizadas
- HTML5 / CSS3 / JavaScript (ES6+)
- Bootstrap 5.3.3
- FontAwesome 6.5.1
- SweetAlert2
- html2pdf.js
